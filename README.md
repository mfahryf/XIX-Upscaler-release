## What is Upscaler?

Upscaler enlarges images and video in batch, and can interpolate video to a higher frame rate.

- **Free trial** — 10 successful files before a licence is required
- **Monthly licence** — one active device at a time
- Batch processing with image engines that run locally and online
- Optional video engine that uses your own Colab GPU and Google Drive account

## Auto-update

Once installed, Upscaler checks this repository for new releases on startup. If a newer version is published here, the app downloads it in the background and prompts you to restart when it is ready.
